## 🧠 Overview

InData is an InDesign plug-in from EM Software that builds documents from external data: records from a spreadsheet or text file are placed into a template with repeating frames, linked images and conditional content. It is developed by EM Software. The product family is positioned as a data merge for indesign toolset for Windows workflows.

InData works as a plug-in suite on Windows 10 and Windows 11 and is installed alongside a host application such as Adobe InDesign CC 2019 or newer.

## 🚀 Key Features

| Feature | Description |
| --- | --- |
| 🗃️ Data Sources | Reads tab- and comma-delimited text as records with named fields. |
| 🔁 Repeating Frames | Repeats a frame or group once per record, growing the document automatically. |
| 🖼️ Image Links | Places a file path per record and replaces the link for every instance. |
| 🧠 Conditional Content | Content is included or skipped according to field values. |
| 📄 One File per Record | Exports each record as a separate INDD or PDF file named from a field. |
| 🧩 Style Mapping | Paragraph and character styles are bound to fields in the template. |

## 💻 System Requirements

| Component | Minimum / Recommended |
| --- | --- |
| Operating System | Windows 10 64-bit or Windows 11 |
| Host Application | Adobe InDesign CC 2019 or newer |
| Memory | 8 GB RAM minimum; large record sets are processed page by page |
| Graphics | GPU with 2 GB VRAM, driver from 2022 or newer |
| Display | 1440 x 900 minimum, colour-calibrated display recommended |
| Storage | 500 MB free disk space plus the linked image folder |
